## What the search does and does not resolve

The published sources establish the rank boundary and several skill 100–120 unlocks. I did not find a source that pairs **a known number of rank S crafts** with **profession skill and percentage before and after**. That means there is no independent rank S calibration for the current model. Continuing the 19.6% per-level growth through skill 100 would be an extrapolation across a rank change, and may fail if XP thresholds or recipe XP change at that boundary.

The project's skill input and targets currently end at 100, and the historical Finder A measurements end near 100. Adding a skill 120 forecast would require at least one rank S craft series with a named recipe, exact recipe count, before/after skill percentages, and badge state. Different rank S recipes should not be assumed to award the same XP as Item Finder A.

The existing 78.4304 → 80 prediction is unaffected by these sources; all its evidence is below rank S. These web findings warrant documenting rank S as an unsupported range, not fitting extra numerical checkpoints from unlock levels.
